# CDPR-G302 电机反馈单位切换全局安全设计

更新日期：2026-10-04

## 1. 问题与结论

【嵌入式模块】中的“电机数据反馈单位（角度/圈数）”不是单纯的显示选项。它同时决定雷赛轴脉冲当量、位置/速度限位、PVT与在线速度换算、Trace位置解释、控制盒速度估算、单电机运动以及六维力交互的电机单位。

控制卡连接期间切换单位，会令板卡轴当量、既有反馈值、软件限位、Trace安全基准和控制线程配置短暂处于不同单位体系。2026-10-04调试中，圈数限位 `[-6.5, 6.5] rev` 在连接状态下切换为角度后被当作 `[-6.5, 6.5] deg` 使用，随即触发软件位置超限。

全局原则如下：

- 角度和圈数两种模式继续保留；
- 单位只能在雷赛控制卡完全断连、整机非运行状态下切换；
- 所有功能模块遵守同一限制，不为六维力交互建立局部特例；
- 六维力交互仍只准入角度单位；
- 连接后允许重新下发“当前未改变的轴当量”，禁止改变单位体系。

## 2. 现有使用范围

单位选择被下列功能共同读取：

- 雷赛轴脉冲当量和电机位置、速度软件限位；
- PVT轨迹、程序控制和仿真结果下发；
- 单电机点位、JOG、绳索电机松半圈；
- 在线速度控制、末端遥控和控制盒速度估算；
- Trace延迟标定、Trace位置/安全相对位置解释；
- 六维力交互阶段B/C/D及离线记录。

这些模块支持在启动前选择合适单位，但没有必须在控制卡在线期间切换单位的需求。六维力交互统一使用角度；原G302模板仍可在断连时选择圈数供旧功能使用。

## 3. 间接修改入口

除两个单位单选按钮外，还有两个程序化入口：

1. 加载G302/Lite参数模板会把单位恢复为圈数，并重写一批以圈数表达的限位参数；
2. 导入完整参数配置文件会恢复单位及对应限位参数。

因此不能只禁用单选按钮。模板加载和完整参数配置导入也必须在控制卡断连时执行。仅包含力控PID参数的专用配置文件不改变单位，可保持原有在线加载能力。

## 4. 实施方案

### 4.1 全局门禁

新增统一判定：只有 `雷赛控制卡未连接 && 整机未运行` 时才允许改变反馈单位。

- 连接后禁用“角度/圈数”控件；
- 断连后重新启用；
- 信号处理函数保留兜底检查，防止程序化 `setChecked()` 绕过控件禁用；
- 若被拒绝，使用 `QSignalBlocker` 恢复原选择，不转换限位、不写轴当量、不刷新控制线程配置。

### 4.2 模板与配置入口

- 控制卡连接或整机运行时，拒绝加载整机参数模板；
- 控制卡连接或整机运行时，拒绝导入完整参数配置；
- 力控PID专用配置不含结构性单位参数，继续沿用原逻辑；
- “更新并应用参数”现有的运行中结构参数跳过策略保持不变。

### 4.3 合法的连接后当量重写

不在 `applyLeadshineAxisEquivFromUi()` 中笼统禁止所有连接状态调用。Trace断连位置恢复、绳索电机松半圈、部分启动和维护流程会重新下发当前单位对应的同一轴当量，这些调用应继续有效。

本次门禁针对的是“单位选择发生改变”，而不是“重新写入未改变的配置”。

### 4.4 六维力交互提示

六维力交互页的红色准入提示改为明确操作顺序：

> 六维力交互统一使用角度单位。请先停止运动并断开雷赛控制卡，再到【嵌入式模块】选择【角度】，然后重新启动整机；控制卡连接期间禁止切换角度/圈数。

## 5. 验证清单

1. 断连时可在角度/圈数间切换，位置和速度限位按360倍正确换算；
2. 连接后两个单位控件不可操作；
3. 通过代码、模板或配置文件尝试改变单位时被拒绝，原单位和限位保持不变；
4. 断连后控件恢复可用；
5. 六维力交互在圈数模式下保持禁用并显示新的红色操作提示；
6. 角度模式下重新启动整机后，六维力交互正常准入；
7. Trace恢复、松半圈和正常启动中重写当前轴当量的流程不受影响。
