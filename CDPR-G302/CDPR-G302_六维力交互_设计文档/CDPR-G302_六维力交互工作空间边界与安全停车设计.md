# CDPR-G302 六维力交互工作空间边界与安全停车设计

## 1. 文档职责

本文只定义六维力交互的边界、安全判据和停车动作。控制链、执行器模板、Trace、阶段 A～D 和时间基准见《CDPR-G302 六维力交互总体架构与实时控制设计》；运行后复算见《CDPR-G302 六维力交互 MATLAB 离线回放设计》。

安全逻辑一旦介入，本次微重力交互试验立即判为无效，之后的命令只服务于安全停车，不能把停车后的轨迹解释为真实微重力响应。

## 2. 统一状态来源

同一套边界检查三类末端状态：

- Newmark 期望位姿：高频、运动前预测；
- 八轴同帧 Trace 经正运动学得到的实际位姿：在线低频或运行后逐帧复算；
- 可选 Nokov 位姿：阶段 D 的独立实测监视，不参与当前控制命令生成。

三者使用同一 G302 几何参数和坐标约定，不再建立“阶段 B 边界”“正运动学边界”等平行概念。

## 3. 几何硬边界

不能只检查动平台质心。将八个平台连接点由局部系变换到全局系，要求全部连接点均位于 G302 机架内部：

```text
X ∈ [-frameLength/2, frameLength/2]
Y ∈ [-frameWidth/2,  frameWidth/2]
Z ∈ [workspaceZMin,  frameHeight]
```

平台自身尺寸已经给质心形成几何余量，因此正运动学搜索范围不再另加容差。初始位姿、每个期望步和每个可用实际位姿都执行相同判定。任一连接点越界均为几何硬边界故障。

姿态限值与连接点几何判定分别报告原因；恢复完整六自由度实验前必须冻结可验证的姿态范围。

## 4. 动态停车边界

对每个连接点与每个边界面计算剩余距离 `d` 和朝外法向速度 `v_out`。公共协同制动的等效平台边缘速度为：

```text
v_eq = ||v_center|| + ||omega|| * r_max
d_stop = max(0, v_out) * v_eq / (2*a_stop)
d_trigger = d_stop + d_margin
```

- `a_stop`：UI 设置且经空载、加载试验验证的最大末端减速度；
- `r_max`：质心到最远平台连接点的距离；
- `d_margin`：覆盖离散周期、驱动响应、跟踪误差和模型误差的保守固定余量；
- 不再单独建立难以验证的“总响应延迟”距离项。

正常区内继续执行力响应。当 `d <= d_trigger` 且下一步仍朝边界加速、保持危险速度，或剩余距离已不足以制动时，冻结外力输入并进入协同减速停车。若当前运动明确远离该边界，则不触发该边界的停车。

## 5. 固定急停边界

在几何硬边界内侧保留一条固定急停线，作为受控制动失败的最后保护：

```text
正常区 → 动态停车边界 → 固定急停线 → 几何硬边界
```

- 动态停车边界：协同减速，试验判为失败；
- 固定急停线：立即停止并锁存故障；
- 几何硬边界越界：最高等级故障，禁止自动恢复。

触发后即使状态重新回到安全区也不能自动恢复本次交互，必须重新准备实验。

## 6. 单轴与绞盘保护

末端边界之外，每轴还必须独立检查：

- 驱动状态字、轴错误码和停止原因；
- Trace 有效性、完整性、连续性和超时；
- 相对启动安全基准的绞盘行程，当前配置为双向最多 6.5 圈；
- 单轴速度、命令变化和延迟对齐后的跟随误差；
- 反馈为非数值、单位/脉冲当量不一致和轴映射错误。

“安全相对位置”是在本次运动首个可靠八轴 Trace 帧锁存的八轴起点。后续行程和跟随误差均相对此基准计算；它不是末端位姿，也不是额外的控制目标。

单轴速度超限时逐轴截断，不允许为了保持八轴比例而整体缩小全部速度命令。截断若破坏运动学一致性，随后由跟随误差或末端实际状态判据终止试验。

## 7. 张力保护（阶段 D）

- D0 空载联调：张力对象仍采集和记录，但物理张力准入、松绳和过张力保护明确旁路；
- D1 接绳实机：八路张力完整、预紧完成、最低张力和最高张力保护必须生效；
- 初始最低张力暂定 10 N，最高允许张力等待实机额定值确认；
- 任一张力对象无效、持续低于下限或高于上限时进入故障停车；
- D0 的旁路状态不能自动继承到 D1，切换 D1 必须二次确认并写入日志。

地面样机中绳索张力承担真实重力，但 Newmark 虚拟动力学仍是无重力纯惯性模型。

## 8. 实际位姿检查

高频控制周期不运行迭代正运动学。默认用八轴同帧 Trace 在 5 Hz 计算实际末端位姿，用于显示、边界监视和趋势判断；运行结束后对全部有效帧离线复算。

若启用 Nokov“仅监视”，其位姿作为第三路独立实测数据参与边界检查和记录，但不替代 Trace，也不闭环修正 Newmark 或速度命令。动捕关闭时必须明确显示“无外部实际位姿反馈”。

## 9. 停车和故障动作

| 事件 | 动作 | 是否锁存 | 试验有效性 |
|---|---|---:|---:|
| 正常运行时间结束 | 以 `a_stop` 协同减速 | 否 | 可有效结束 |
| 动态停车边界触发 | 冻结外力并协同减速 | 是 | 无效 |
| 跟随误差、张力、行程或 Trace 故障 | 停止八轴并锁存 | 是 | 无效 |
| 固定急停线、轴故障或几何越界 | 立即停止/失能链 | 是 | 无效 |

驱动失能或断电后由电机抱闸保持平台，因此不另建软件“防坠落运动”。正常情况下仍优先受控停车，并记录抱闸、驱动状态和停车原因。

## 10. 独立安全监控

独立安全监控只消费控制线程发布的轻量快照，不应在控制线程中同步写 CSV、拟合或执行耗时正运动学。快照至少包含主机时间、会话状态、八轴命令/反馈有效性、边界余量、Trace 健康和故障状态。

标定、运行后保存等非运动阶段应进入有界的专用状态，而不是粗暴关闭全局看门狗。断连时必须统一终止会话、恢复 Trace 所有权并复位各子页 UI。

## 11. 记录与验收

每次运行至少记录：边界参数快照、最小余量和对应连接点、停车触发距离、首个触发原因、八轴命令/反馈、张力、Trace 序号、状态字、计算/API耗时和最终停车结果。

阶段 D 的验收顺序为：

1. D0 空载，关闭动捕，验证最终控制链、Trace、日志和全部非张力保护；
2. D0 可选接入动捕，仅检查时间戳、坐标和记录；
3. 静态接绳，验证轴—绞盘—绳索方向、预紧和张力上下限；
4. D1 仅平动、小力、短时、低速；
5. 比较 Newmark 期望、Trace 正运动学和可选 Nokov 位姿后再扩大范围；
6. 最后才开放姿态响应。
