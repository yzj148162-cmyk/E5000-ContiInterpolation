# CDPR-G302 六维力交互 MATLAB 离线回放设计

## 1. 文档职责

本文只定义 Qt 运行记录如何由 MATLAB 离线重建、分析和动画显示。实时控制、Trace 配置和阶段 A～D 见《CDPR-G302 六维力交互总体架构与实时控制设计》；安全判据见《CDPR-G302 六维力交互工作空间边界与安全停车设计》。

Qt 与 MATLAB 完全解耦：Qt 不调用 MATLAB、不等待分析结果；MATLAB 手动读取 Qt 导出的 CSV/JSON，不回写在线控制或安全状态。

## 2. 入口与目录

独立回放工程位于：

```text
CDPR-G302/matlab_offline_replay/
```

入口函数：

```matlab
result = replay_force_interaction_run(configFile, options)
```

`configFile` 为空时，文件选择框应默认定位到最近一次 Qt 记录目录并选择 `*_replay_config.json`。根目录旧《MATLAB代码》只作算法参考，回放工程运行时不依赖也不修改它。

## 3. Qt 导出协议

一次实验导出一对文件：

```text
force_interaction_*.csv
force_interaction_*_replay_config.json
```

CSV 保存逐周期运行量，JSON 保存本次准备时冻结的模型和映射。JSON 至少包含：

- 八个全局出绳点和平台局部连接点；
- 初始末端位姿、初始绳长、运行起点 Trace 位置；
- 绳索号—控制卡轴号—从站号—实体绞盘映射；
- 电机方向、收放绳符号、脉冲当量、减速比和绞盘模型；
- 长度、角度、姿态、力和时间单位；
- 总线周期、Trace 实际周期、控制周期和延迟标定快照；
- 工作空间和停车参数；
- `stage`、`mechanical_mode`（D0/D1）和 `mocap_mode`。

CSV 至少包含：

- 主机单调时间、模型时间、Trace 序号和有效标志；
- 原始/去零/滤波后的六维力；
- Newmark 期望位姿、速度和加速度；
- 八绳期望长度、八轴期望位置、速度命令和同帧 Trace 位置/速度；
- 边界余量、运行/制动状态、停车原因和耗时；
- 阶段 D 的八路张力；
- 启用 Nokov 时的时间戳、有效标志和实测位姿。

原始 CSV/JSON 始终只读，MATLAB 输出写入记录目录下的 `analysis/`。

## 4. 有效帧筛选

正运动学只接受：

1. Trace 帧有效且序号严格递增；
2. 同一帧八轴位置全部为有限数值；
3. 轴映射、单位和初始基准完整；
4. 处于允许分析的交互或制动区段。

八轴必须作为同一物理时刻整体处理。各轴延迟标定只用于误差诊断，不能把八根绳分别平移到八个时刻后再做正运动学。

## 5. 离线计算链

```text
读取 JSON/CSV
  → 校验版本、单位、映射和完整性
  → 筛选同帧八轴 Trace
  → 电机角度换算为绞盘放绳量
  → 初始绳长 + 放绳量得到八绳长度
  → 使用上一帧解作初值求六自由度正运动学
  → 统一几何边界复算
  → 比较期望、Trace正运动学和可选Nokov位姿
  → 统计、曲线、动画和可选视频
```

当前尚未启用完整排绳模型时，固定半径换算必须在 JSON 中明确标记为回退模型；不能把回退结果误写成精确实机绳长。

## 6. 图形和动画

单个 Figure 同步显示：

- G302 机架、八根绳索和完整动平台二十面体边线；
- 期望平台、Trace 正运动学平台和可选 Nokov 平台；
- 三维力随时间曲线；
- 期望/实际位置与姿态随时间曲线；
- 当前时间、阶段、机械模式、边界余量和停车原因。

动画支持重复运行，也可通过 `WriteVideo=true` 保存视频。视频和分析 CSV/JSON 写入本次记录的 `analysis/` 目录。

主要选项：

```matlab
options.Animate = true;          % 播放动画
options.IncludeBraking = false;  % 是否包含停车段
options.WriteVideo = false;      % 是否输出视频
options.FrameStride = 1;         % 每隔多少有效帧绘制一次
options.MaxFrames = inf;         % 最多处理多少帧
```

## 7. 输出指标

- 有效/拒绝帧数、Trace 断裂和非递增次数；
- 正运动学收敛率、迭代数、八绳残差 RMS/最大值；
- 期望与 Trace 正运动学的平移/姿态误差；
- 启用动捕时，期望—Nokov及Trace正运动学—Nokov误差；
- 最小几何边界余量和首次停车/故障时刻；
- 八路张力最小/最大值及阶段 D 越限事件；
- 分析使用的配置文件、源 CSV 和软件版本。

空转所得“实际位姿”只是按编码器和假定绞盘关系重建的虚拟结果，可验证八轴同步、映射和运动学一致性，不能替代真实张力、绳索弹性、打滑、结构变形或动捕测量。

## 8. 阶段 D 使用方式

- D0 空载联调：验证最终日志协议、八轴运动学一致性、张力通道记录和停车事件；
- D1 接绳实机：在同一脚本中加入张力曲线与真实边界分析；
- 动捕关闭：比较 Newmark 期望与 Trace 正运动学；
- 动捕仅监视：增加 Nokov 第三条实测轨迹，不改变回放主链；
- D0 与 D1 必须在标题、配置摘要和输出报告中明显区分。

## 9. 验收

1. Qt 不安装 MATLAB 也能正常控制和导出；
2. MATLAB 不读取 Qt 进程内存，也不依赖旧 MATLAB 工程；
3. 同一记录重复运行得到一致结果；
4. MATLAB 与 C++“验算最近运行”在同一有效帧、模型和映射下结果一致；
5. 映射、单位、参数或数据缺失时明确拒绝，禁止猜测；
6. 长记录可抽帧播放，但统计必须覆盖全部有效帧；
7. Stage D 的张力和可选 Nokov 数据不影响 Stage B/C 旧记录兼容性。
