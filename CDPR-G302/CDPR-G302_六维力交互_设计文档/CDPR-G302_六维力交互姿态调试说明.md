# CDPR-G302 六维力交互姿态调试说明

## 1. 目的与当前安装

本文只记录 G302 六维力交互由“仅平动”过渡到姿态响应时的边界和实施原则。

当前六维 F/T 传感器按以下等效关系进入动力学：

```text
R_ES = I
r_ES_E = [0, 0, 0]^T m
```

即传感器三轴与动平台局部坐标系同向，测量参考点等效位于动平台质心。去零后的
`[Fx,Fy,Fz,Mx,My,Mz]` 直接作为质心局部系力旋量，不再由平移力臂产生附加力矩。

历史配置为 `R_ES=I、r_ES_E=[0,0,0.32548]^T m`，表示测量点位于质心正上方
325.48 mm。该值只为旧日志和旧回放结果追溯而保留，当前程序不再使用。

## 2. 两套现有工作边界

### 2.1 G302末端遥控

- 质心位置固定在 `X/Y∈(-500,500) mm、Z∈(400,1400) mm`；
- 位置空间划分为 8000 个 `50×50×50 mm` 体素；
- 每个体素保存 Rx/Ry 允许范围，当前半角约为 `2°～16.25°`；
- 平动时 Rx/Ry 使用全部体素公共交集，约为 `±2°`；
- Rz进入遥控时锁存，硬边界为 `±5°`，允许平动的范围为 `±2.5°`；
- 平动停车轨迹会检查沿途体素，不能进入姿态不兼容的相邻格子。

### 2.2 六维力交互

- 不使用固定质心立方体，而是要求旋转、平移后的8个平台连接点全部位于机架内：
  `X/Y∈[-1400,1400] mm、Z∈[-100,2670] mm`；
- 默认动态停车距离为 `v²/(2a)+50 mm`，其中默认 `a=500 mm/s²`；
- 距物理边界 `10 mm` 内进入固定急停线；
- 另有绞盘行程、单轴速度、跟随误差、驱动状态、Trace及D1张力保护；
- 当前没有独立的Rx/Ry/Rz硬边界，也没有在线绳索干涉、雅可比条件数或姿态张力可行性判定。

## 3. 现有末端遥控体素表不能直接接入

现有CSV只能作为实现参考，不能原样作为六维力交互的正式姿态边界：

1. 表的Z范围从400 mm开始，而当前六维力实验常用起点约为Z=100 mm；
2. 表只包含Rx/Ry，末端遥控中的Rz被锁存，不能覆盖完整六自由度响应；
3. 表来自旧版G302几何分析，当前静态出绳点已经重新标定；
4. 六维力期望轨迹由Newmark连续产生，需要同时检查当前状态和受控停车轨迹。

可复用的是CSV加载、常数时间索引和跨体素路径检查代码，而不是当前CSV数值。

## 4. 后续姿态可行域方案

使用最新G302出绳点、平台连接点和实际D1工作区，离线生成六维力交互专用可行域。
离线判据至少包括：

- 平台连接点几何边界；
- 绳索—绳索及绳索—平台干涉；
- 雅可比矩阵条件数或等效奇异性指标；
- 必要时加入张力分配可行性；
- Rx、Ry、Rz联合姿态范围及保守安全余量。

实时5 ms控制只进行查表、相邻格检查和安全余量判断，不在每周期执行完整张力优化。
低频诊断可以计算绳索距离和雅可比指标，但不能代替运动前的确定性边界。

## 5. 调试顺序

1. 保持“仅平动调试”，确认当前F/T零点、符号、三轴方向和D0/D1平动链正常；
2. 在阶段A取消“仅平动调试”，分别施加单轴Mx、My、Mz，核对姿态方向和八轴符号；
3. 在D0空转中使用小力矩、短时间、低速度验证完整Trace、停车和离线回放；
4. 专用姿态可行域表生成并接入安全链后，再进行D1单轴小角度姿态响应；
5. 比较Newmark期望、Trace正运动学和Nokov低频位姿，再逐步扩大力矩和角度范围；
6. 未完成干涉、奇异性和张力可行域验收前，不开展多轴大姿态实验。
