# CDPR-G302 六维力交互执行器模板与 Trace 精简设计

## 1. 目的与当前结论

本设计服务于 G302-CDPR 最终六维力交互控制。当前先使用与 `cdpr_control`
相同的8台电机和驱动器，在断开联轴器、绞盘和绳索的条件下完成模拟六维力空转。

当前阶段B的数学与实时控制主链已经写入 `CDPR-G302`：

`模拟六维力 → S到E质心力旋量变换 → 纯惯性 Newmark-β → 八绳逆运动学
→ 八轴速度前馈（位置PID仅预留） → 雷赛在线变速 → Trace反馈 → 记录与边界复算`

UI已有“六维力交互/电机空转（阶段B）”子页，准备、启动、减速停止、立即停止、
运行记录、5 Hz虚拟正运动学和安全状态机均已接入。当前准确状态是：

> 阶段B首版代码链已经完成，但尚未通过本组替代电机的硬件初始化和空转验收，
> 因此不能称为阶段B验收完成。

现阶段的首个阻塞不是阶段B算法，而是完整整机启动仍无条件写入原G302电机/驱动器
专用的转矩模式参数。

## 2. 本次错误的确定原因

点击“启动整机”时，`MainWindow::runFullSystemSwitch()`依次执行：

1. `applyLeadshineHardwareConfigFromUi()`建立电机轴、从站、脉冲当量、限位和Trace模板；
2. `HardwareInterface::connectLS()`打开控制卡；
3. 对每个电机轴调用`dmc_set_equiv()`；
4. 读取各轴当前位置并建立启动位置快照；
5. 对所有非直线模组电机调用`applyLeadshineTorqueVelocityLimit()`；
6. 通过`nmc_set_node_od()`向驱动器写入`220Bh:00h`；
7. 随后才会清错、使能、建立安全相对零点、启动控制线程并执行整机自检。

第5～6步当前是无条件的。程序还把原G302驱动系统的
`360000 pulse/电机圈`写死在换算中，因此：

`450 rpm × 360000 pulse/rev ÷ 60 = 2700000 pulse/s`

从站1003不接受该对象或该写法，返回错误码74。`connectLS()`把任一220Bh写入失败
视为完整连接失败，立即关闭板卡，所以程序没有进入使能和阶段B准备阶段。

220Bh只服务于转矩模式速度限制；阶段B使用`dmc_vmove + dmc_change_speed_unit`
进行速度模式位置闭环，不需要写入该对象。这里应按启动用途裁剪，而不能简单吞掉
所有SDO错误。

## 4. 模板必须分成两个正交概念

不能因为替换了电机，就改动G302的机构模型。程序需要把以下两个概念分开：

### 4.1 机构模板

继续选择`G302`，负责：

- 出绳点和动平台连接点；
- 质量、惯量和F/T安装变换；
- CDPR绳索编号和电机轴编号关系；
- 电机转动与收放绳的符号约定；
- 逆运动学、正运动学和末端工作空间边界。

### 4.2 六维力交互执行器模板

该模板是整个“六维力交互”页面的专属共享配置，应放在阶段A、B、C、D各子页
上方，而不是放入阶段B子页内部。模板不属于程序其他运动页面。

提供两项：

- `G302原执行器`：维持现有完整整机初始化行为；
- `通用增量编码器8轴`：使用当前替代电机，执行最小速度控制初始化。

选择第二项时，模板只冻结：

- 8个逻辑轴对应的控制卡轴号；
- 每轴脉冲当量（临时8轴公共值固定按`180224/360 = 500.622222222 pulse/°`）；
- 工程单位，建议仍统一为`1 unit = 1°`；
- 阶段B速度上限、位置跟随误差上限和Trace超时；
- 增量编码器会话零点策略。

阶段A不访问硬件，因此执行器模板选择只作界面共享配置，不参与阶段A的数学
通过判定；阶段B启动硬件会话时冻结模板及脉冲当量，阶段C继续使用同一模板接入真实F/T；阶段D在恢复原执行器或
完成替代执行器实机验收后继续沿用。模板切换只能在所有六维力交互任务停止时
进行，运行期间冻结。

本模板不修改机构模板，不覆盖原G302电机参数，也不能被PVT、末端遥控、转矩测试、
原力控或其他页面使用。

## 5. 推荐的代码隔离方式

### 5.1 显式初始化策略

不要在`connectLS()`中根据某次错误码猜测是否忽略220Bh。增加明确策略，例如：

```text
LeadshineStartupPurpose::FullG302Machine
LeadshineStartupPurpose::ForceInteractionMotorOnlyDebug
```

公共连接流程复用“开卡、轴映射、脉冲当量、位置读取、清错、使能”；策略只决定
是否执行原电机专属步骤。

`FullG302Machine`保持当前行为不变。`ForceInteractionMotorOnlyDebug`应当：

1. 连接控制卡并检查8轴；
2. 设置8轴脉冲当量；
3. 读取8轴当前位置；
4. 跳过220Bh、额定转矩和转矩反馈初始化；
5. 清错并使能8轴；
6. 以本次位置建立临时安全相对零点；
7. 启动控制线程和安全监控；
8. 将硬件状态标记为“阶段B电机调试就绪”，而不是“完整G302实机就绪”。

### 5.2 功能互锁

处于“六维力交互替代电机就绪”时：

- 只开放六维力交互A～D阶段中与当前验收阶段相符的操作、停止和全局急停；
- 禁止PVT、末端遥控、转矩模式、张力/预紧和真实收放绳操作；
- 停止或故障后八轴速度归零；立即停止时调用全轴急停；
- 断开后清除临时零点和调试模板快照；
- 不写回原G302执行器配置。

这能保证替代电机调试不会改变其他功能的默认逻辑。

## 6. 阶段B Trace对象

`cdpr_control`中的六维力交互使用`TraceFeedbackProfile::VelocityControl`，当前实际配置为：

- type 3：8轴板卡指令速度；
- type 4：8轴实际速度；
- type 6：8轴实际位置。

合计24个电机对象，没有力矩反馈对象，也没有速度模式下无控制意义的
type 5板卡指令位置。这套对象已在当前替代电机和驱动器上使用，应作为G302-CDPR
阶段B的参考。

G302-CDPR当前通用Runtime Trace还会加入指令位置、状态字和实际转矩等对象。
现已新增独立的`ForceInteractionVelocity`用途配置，未改动其他模式的对象集合：

```text
阶段B控制/记录：type 3/4/6 × 8 = 24对象
同帧安全：0x6041状态字 × 8 = 8对象
阶段B当前合计：32对象
最终真实F/T：上述32对象 + 同帧六维力6对象 = 38对象
```

临时模板启动安全零点使用同一Trace帧内的8轴**实际位置**。该用途有意不采集
板卡指令位置，因此底层发布位置快照和锁存会话零点均不得把“存在指令位置对象”
作为前置条件。启动最多等待3.5 s，250 ms仍未取得可靠帧时允许清空并重启一次
Trace；失败日志必须输出配置回读、时序可靠性、FIFO追平、丢帧、帧有效性和帧龄。

真实F/T的6个对象索引目前未知，保持未配置；模拟力阶段不得因为它们为空而拒绝
启动。状态字保留是因为阶段B现有安全链要求每个控制反馈帧中的8轴均为
`Operation enabled`；它属于安全对象组，不是控制输入。指令位置和反馈转矩已从
该profile删除。

## 7. 六维力交互页面布局与阶段B入口

“六维力交互执行器模板”位于六维力交互页面标题/总状态下方、A/B/C/D子页签
上方。它与机构模板并列显示，但职责不同：机构模板决定G302几何，执行器模板
决定本页硬件初始化能力。所有子页共享同一份只读摘要，只有空闲状态允许编辑。

操作入口位于：

`六维力交互 → 电机空转（阶段B）`

现有顺序是：

1. 在“软件验证（阶段A）”设置并校验模拟六维力；
2. 在阶段B页设置周期、时长、速度前馈和安全阈值；PID控件保留但默认关闭；
3. 点击“准备阶段B”冻结模拟力、动力学、机构、边界及八轴控制参数；
4. 点击启动，等待可靠的八轴同帧Trace；
5. 周期执行Newmark、逆运动学、八轴速度前馈和在线变速；只有以后主动启用时
   才叠加位置PID修正；
6. 时长到达或用户正常停止时冻结力输入并协同减速；
7. 故障或急停时立即停止；
8. 会话结束后关闭异步记录，并后台执行边界日志复算。

现有启动条件包括：G302机构模板、完整8轴、8轴均使能、速度上限不超过轴安全
上限、没有其他运动任务、控制线程运行、Trace可靠、无安全故障锁存。六维力
交互执行器模板实施后，仅替换本页“硬件如何初始化”，这些运行条件仍保留。

## 9. 替代电机空转测试步骤

实施上述代码后按以下顺序测试。

### 9.1 静态准备

1. 确认8台电机均未连接联轴器、绞盘和绳索，急停可用；
2. 机构模板选择G302；
3. 在子页上方的六维力交互执行器模板中选择“通用增量编码器8轴”；
4. 填入已在`cdpr_control`验证的脉冲当量；
5. 首次测试选择5 ms控制周期、1 s最长运行时间；
6. 速度上限从低值开始，位置PID关闭，速度前馈开启；
7. 模拟六维力设为全零，并勾选“仅平动”。

### 9.2 零输入测试

1. 点击阶段B专用的硬件准备入口；
2. 检查日志必须显示：8轴在线、8轴当量写入成功、位置可读、220Bh已按策略跳过、
   8轴使能成功；
3. 点击“准备阶段B”，再点击启动；
4. 8台电机应保持静止，运行到时后正常收尾；
5. 日志中Trace应连续、无丢帧、无API失败、记录丢弃为0。

### 9.3 小力单方向测试

1. 使用常值`Fx=0.05 N`，其余分量为0，最长运行1 s；
2. 观察8轴是否平滑启动、速度符号是否符合虚拟G302逆运动学结果；
3. 会话结束后查看CSV中的期望位置、期望速度、实际位置、实际速度和命令速度；
4. 检查5 Hz虚拟正运动学得到的实际末端位姿是否沿+X方向变化；
5. 检查边界离线复算结论与在线结论一致。

随后依次测试`Fy`、`Fz`，每次只打开一个分量。空转初期继续屏蔽三维力矩。

### 9.4 后续可选PID试验（不属于近期阶段B验收）

近期只验收纯速度前馈，PID按钮作为未来功能暂留，不要求开启。需要研究位置修正
效果时，必须另开试验批次：

1. 在纯速度前馈已经独立通过后启用位置PID；
2. 从小Kp开始，Ki和Kd先置零；
3. 对比开启前后的八轴位置跟随误差和虚拟末端误差；
4. 再测试低频正弦或公式输入，最后延长运行时间；
5. 任一轴跟随误差、Trace超时、API失败或边界保护触发均应使本次试验失效并记录
   明确原因。

## 10. 通过判据

阶段B替代电机空转至少满足以下条件才算通过，PID无需开启：

- 8轴无需写220Bh即可稳定完成连接、清错和使能；
- 32个阶段B Trace对象配置成功（24个位置/速度对象+8个状态字），连续取得八轴
  同帧反馈；
- 零力时无持续漂移命令；
- 单方向小力下8轴命令方向与逆运动学一致；
- 正常时长结束能够协同减速，手动减速停止和立即停止均有效；
- 纯速度前馈命令、位置跟随误差诊断、速度限幅、Trace超时和API故障保护均可复现；
- 记录文件无丢弃，在线边界动作与离线复算一致；
- 5 Hz虚拟正运动学的末端运动方向、量级与Newmark期望相符。

阶段B通过仅说明“模拟力—动力学—运动学—八轴空转控制链”有效，不代表连接绞盘、
绳索后的G302-CDPR实机六维力交互已经验收。
